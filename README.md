# Maliaras Parent — αναφορές σχολείου για γονείς

Διαβάζει τις καταχωρίσεις μαθημάτων των παιδιών σας από το **erp.maliaras.gr** και
σας δίνει μια καθαρή καθημερινή αναφορά στα ελληνικά:

- 🏠 **Για το σπίτι** — εργασίες ανά μάθημα, με ακριβείς σελίδες και ασκήσεις
- 🎒 **Τι να βάλει στην τσάντα** — βιβλία και τετράδια για την επόμενη μέρα
- 📝 **Τι έκαναν** — σύντομη περίληψη ανά μάθημα
- 🗓️ **Πρόγραμμα** — τα μαθήματα της μέρας και της επόμενης σχολικής μέρας

Λειτουργεί μέσα από το **Claude Code** (ή το Pi): ρωτάτε με απλά λόγια, π.χ.
«Δώσε μου την αναφορά της Άννας», και ο βοηθός κάνει τα υπόλοιπα.

> **Μόνο ανάγνωση.** Το εργαλείο δεν στέλνει, δεν αλλάζει και δεν «διαβάζει» τίποτα
> στο ERP για λογαριασμό σας. Οι αναφορές μένουν στον υπολογιστή σας.
>
> **Ανεπίσημο εργαλείο.** Δεν έχει σχέση με το σχολείο ή με τους διαχειριστές του
> ERP. Χρησιμοποιήστε το με δική σας ευθύνη και μόνο με τους δικούς σας κωδικούς,
> για τα δικά σας παιδιά.

## Τι χρειάζεστε

- Mac (ή Linux). Η αποστολή στο Viber λειτουργεί μόνο σε Mac.
- Τους κωδικούς του **erp.maliaras.gr** για κάθε παιδί.
- [**uv**](https://docs.astral.sh/uv/) για να τρέχουν τα scripts:
  ```sh
  curl -LsSf https://astral.sh/uv/install.sh | sh
  ```
- [**Claude Code**](https://claude.com/claude-code) (ή Pi) για να κάνετε ερωτήσεις.
- `curl` (υπάρχει ήδη σε Mac/Linux).

## Εγκατάσταση (5 λεπτά)

**1. Κατεβάστε το project**

```sh
git clone https://github.com/pvendras/maliaras-parent.git
cd maliaras-parent
```

**2. Δηλώστε τα παιδιά και τους κωδικούς σας**

```sh
cp .env.example .env
open -e .env        # ή οποιονδήποτε editor
```

Συμπληρώστε το `.env`:

```sh
# Λατινικό κλειδί : όνομα που θα φαίνεται. Ένα ή περισσότερα παιδιά.
MALIARAS_STUDENTS=anna:Άννα,nikos:Νίκος

# Για κάθε κλειδί: MALIARAS_<ΚΛΕΙΔΙ ΜΕ ΚΕΦΑΛΑΙΑ>_USERNAME / _PASSWORD
MALIARAS_ANNA_USERNAME=...
MALIARAS_ANNA_PASSWORD=...
MALIARAS_NIKOS_USERNAME=...
MALIARAS_NIKOS_PASSWORD=...

# Προαιρετικά: το κανάλι Viber όπου επικολλάτε τις αναφορές
MALIARAS_VIBER_CHAT="Γονείς Β2"
```

- Το κλειδί (`anna`) είναι μόνο λατινικά πεζά και μπαίνει στις εντολές και στα ονόματα αρχείων.
- Τιμές με κενά μπαίνουν σε εισαγωγικά.
- Το `.env` **δεν** ανεβαίνει στο git. Μην το στέλνετε σε κανέναν.

**3. Ελέγξτε ότι όλα δουλεύουν**

```sh
set -a; source .env; set +a
uv run --no-project client.py --list-students        # δείχνει τα παιδιά σας
uv run --no-project lessons.py --student anna --report
```

Αν δείτε JSON με μαθήματα, η σύνδεση πέτυχε. Αν δείτε σφάλμα σύνδεσης, ελέγξτε
τους κωδικούς στο `.env`.

**4. Ανοίξτε το Claude Code**

Το skill είναι ήδη συνδεδεμένο (`.claude/skills/maliaras-parent`). Ανοίξτε το
Claude Code **μέσα στον φάκελο** `maliaras-parent` και γράψτε:

```text
/maliaras-parent αναφορά Άννας
```

Για το **Pi**: ανοίξτε το Pi στον φάκελο (το skill είναι στο `.agents/skills/`) ή
φορτώστε το ρητά με `pi --skill <φάκελος>/.agents/skills/maliaras-parent/SKILL.md`.

## Καθημερινή χρήση

| Τι θέλετε | Τι γράφετε στο Claude Code |
|---|---|
| Αναφορά της ημέρας | `/maliaras-parent αναφορά Άννας` |
| Αναφορά και αποστολή στο Viber | `/maliaras-parent αναφορά Άννας και στείλ' τη στο Viber` |
| Ένα μάθημα | «Τι έχει η Άννα για το σπίτι στα Μαθηματικά;» |
| Συγκεκριμένη μέρα | «Τι έκαναν την Παρασκευή;» |
| Πρόγραμμα | «Τι μαθήματα έχει ο Νίκος την Πέμπτη;» |
| Ανακοινώσεις | «Ανακοινώσεις της Άννας» |
| PDF / Markdown | «Βγάλε PDF την αναφορά» |

Αν έχετε πάνω από ένα παιδί και δεν πείτε ποιο, ο βοηθός θα ρωτήσει.

### Viber

Το μήνυμα για το Viber έχει την ίδια μορφή με την αναφορά, **χωρίς το όνομα του
παιδιού** και χωρίς συνδέσμους, και σταματά στο πρόγραμμα. Ο βοηθός το βάζει στο
πρόχειρο και ανοίγει το Viber· εσείς πηγαίνετε στη συνομιλία, πατάτε **Cmd+V** και
αποστολή. **Τίποτα δεν στέλνεται αυτόματα.**

### Αυτόματη αποθήκευση

Κάθε φορά που χρησιμοποιείτε το skill, αποθηκεύεται τοπικά ένα PDF και ένα Markdown
για κάθε νέα ή αλλαγμένη σχολική μέρα όλων των παιδιών, στον φάκελο `reports/`
(π.χ. `reports/anna-report-2026-11-10.pdf`). Αμετάβλητες μέρες δεν ξαναγράφονται.
Αν δεν το θέλετε, πείτε στον βοηθό «χωρίς export».

## Τι να έχετε υπόψη

- Η αναφορά δείχνει **ό,τι καταχώρισαν οι δάσκαλοι** εκείνη τη μέρα. Δεν ξέρει αν
  έγινε η εργασία, ούτε μεταφέρει παλαιότερες εκκρεμότητες.
- Το πρόγραμμα είναι το **σταθερό εβδομαδιαίο**: δεν δείχνει αργίες, εκδρομές ή
  αντικαταστάσεις. Οι ώρες λήξης είναι εκτίμηση (έναρξη + 45′).
- Δεν καλύπτονται ακόμα: συνημμένα, βαθμοί, γενικές ανακοινώσεις σχολείου,
  ημερολόγιο αργιών, προηγούμενες σχολικές χρονιές.
- Το ERP δεν έχει δημόσιο API· αν το σχολείο το αλλάξει, κάτι μπορεί να σταματήσει
  να δουλεύει.

## Ιδιωτικότητα

- Οι κωδικοί μένουν στο `.env` σας και δεν εμφανίζονται ποτέ σε έξοδο.
- Οι αναφορές (`reports/`) μένουν στον υπολογιστή σας και δεν μπαίνουν στο git.
- Όταν ρωτάτε τον βοηθό, το κείμενο των μαθημάτων που χρειάζεται για την απάντηση
  περνά στη συνομιλία με το Claude.
- Το κείμενο των δασκάλων αντιμετωπίζεται ως πληροφορία, ποτέ ως εντολή.

## Για προχωρημένους

### Εντολές χωρίς βοηθό

Πριν από κάθε εντολή: `set -a; source .env; set +a`

```sh
uv run --no-project lessons.py --student anna --report                     # τελευταία μέρα
uv run --no-project lessons.py --student anna --report --date 2026-09-11   # συγκεκριμένη μέρα
uv run --no-project lessons.py --student anna --report --pdf --md          # αποθήκευση αρχείων
uv run --no-project lessons.py --student anna --report --viber             # απλό μήνυμα Viber
uv run --no-project lessons.py --student anna --subject 'Γλώσσα'           # ένα μάθημα
uv run --no-project lessons.py --student anna --all --date 2026-09-11      # όλα τα μαθήματα μιας μέρας
uv run --no-project lessons.py --student anna --list                       # λίστα μαθημάτων
uv run --no-project schedule.py --student anna [--date ΗΗΗΗ-ΜΜ-ΗΗ] [--week]
uv run --no-project announcements.py --student anna [--subject 'Γλώσσα'] [--limit 20]
uv run --no-project sync_exports.py                                        # αποθήκευση όλων των ημερών
```

Η έξοδος είναι JSON. Οι ημερομηνίες είναι σε ώρα Αθήνας.

### Αρχεία

| Αρχείο | Ρόλος |
|---|---|
| `client.py` | Σύνδεση στο ERP (μόνο ανάγνωση, HTTPS μέσω `curl`), ρυθμίσεις παιδιών |
| `lessons.py` | Μαθήματα, αναφορά ημέρας, εξαγωγές |
| `schedule.py` | Εβδομαδιαίο πρόγραμμα |
| `announcements.py` | Ανακοινώσεις από τις καρτέλες μαθημάτων |
| `sync_exports.py` | Αυτόματη αποθήκευση PDF/Markdown χωρίς διπλότυπα |
| `report_md.py`, `report_pdf.py`, `report_viber.py` | Μορφές εξόδου |
| `.agents/skills/maliaras-parent/SKILL.md` | Οδηγίες για τον βοηθό (Claude Code / Pi) |
| `mcp_server/` | Προαιρετικός MCP server για Kubernetes (δείτε το δικό του README) |

### Ασφάλεια του client

Επιτρέπονται μόνο αιτήματα στο `https://erp.maliaras.gr/api/…`. POST μόνο για
σύνδεση και για το πρόγραμμα (που το ERP το ζητά ως POST). Δεν ακολουθούνται
redirects, cookies και απαντήσεις μένουν μόνο στη μνήμη, και οι κωδικοί περνούν
στο `curl` από stdin, όχι από τη γραμμή εντολών.

### Tests

```sh
uv run --no-project --with reportlab --with pypdf python -m unittest discover -s tests -t .
cd mcp_server && uv run --group dev pytest -q
```

Τα tests χρησιμοποιούν φανταστικά παιδιά (`anna`, `nikos`) και δεν συνδέονται στο ERP.
Για τα ελληνικά στο PDF χρειάζεται Arial (macOS) ή DejaVu Sans (Linux).
